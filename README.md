# Grok macOS Simulator

Lightweight browser-based mockup of macOS Tahoe (entertainment only).

## Features
- Boot animation
- Menu bar + liquid-glass Dock
- Draggable windows (Finder, Safari, Messages, Mail, Photos, Music, Notes, Settings)
- Mock Siri (rule-based replies)
- Dark glassmorphism UI

## Run
Open `index.html` in a modern browser.

Not a real OS. Approximate and simplified for fun.
