# Lumen Desktop

A **browser mock** of a modern glass-style desktop OS inspired by recent macOS Liquid Glass design (macOS 27 Golden Gate refinements).

**Entertainment only.**

**Not macOS. Not Apple. Not the real Siri. Not Apple Intelligence. Not the App Store.**

Official Apple icons, wallpapers, Liquid Glass trademarks, and system chrome are copyrighted. This project uses original SVG icons (squircles with layered glass highlights), original CSS glass surfaces with specular and blur, and original wallpaper scenes. No official Apple assets are used. Changed enough from any real OS to be a distinct entertainment mock.

The assistant (Aura / mock Siri) is a local helper with a tiny LLM phrase model loaded at boot, plus optional third-party AI text endpoint (pollinations.ai) for longer conversational answers. It can open mock apps, save notes, add reminders, do simple math, and speak (optional).

## Recent refinements (Lumen 84)

- Deeper Liquid Glass: higher blur/saturation, improved specular highlights, refined dock magnification & window chrome
- Higher-detail original SVG icons with better gradients, layers, and glass effects
- Stronger Aura AI (local phrase model + improved cloud prompts for more natural responses)
- Polished animations, widgets, Control Center, and overall fidelity
- Tiny local phrase model load on boot screen remains

## Features

- Boot screen with tiny local LLM load
- Lock screen, desktop with widgets, dock magnification, Launchpad, Mission Control, Spotlight-style search
- Control Center with Liquid Glass intensity slider
- Full working mock apps: Files, Notes, Calculator, Web, Gallery (app store mock), Settings, Calendar, Music, Photos, Terminal, Mail, Maps, Stickies, Weather, Clock, Writer, Reminders, and more
- Siri-style AI assistant (local + optional cloud) with speech input/output
- Original high-detail icons and glass effects
