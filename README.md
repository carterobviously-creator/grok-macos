# Lumen Desktop

A **browser mock** of a glass-style desktop. Entertainment only.

**Not macOS. Not Apple. Not Siri. Not Apple Intelligence. Not the App Store.**

Official Apple icons, wallpapers, Liquid Glass trademarks, and system chrome are copyrighted. This project does **not** use them. Icons are original SVGs. Wallpapers are original CSS gradients and animations. Surfaces use original glass-style CSS with adjustable blur, opacity, and specular highlights.

Aura is a local helper that loads a tiny phrase model at boot. It can open mock apps, save notes, add reminders, do simple math, speak, and optionally use a public text demo for longer answers. It is not a product AI and not an Apple assistant.

## Lumen 71 refinements
- Dynamic Liquid Glass slider in Control Center that adjusts blur, opacity, saturation, and specular highlights across glass surfaces
- Consistent modern window corner radii
- Enhanced liquid-style wallpaper animation
- Boot screen loads tiny local model
- Aura already supports local TinyMind + optional cloud AI replies (pollinations demo)

## Features
- Boot screen that loads a tiny local phrase book / model
- Lock screen, desktop icons, widgets
- Glass surfaces with blur + continuous tint/Liquid Glass slider + specular highlight
- Dock hover magnification with neighbor scale
- Wallpaper scenes with Ctrl/Cmd+W and dusk wash with Ctrl/Cmd+D
- Launchpad (F4) and Mission Control (F3)
