# Lumen Desktop

Browser mock of a glass-style desktop. Entertainment only.

**Not macOS. Not Apple. Not Siri. Not Apple Intelligence. Not the App Store.**

Official Apple icons, wallpapers, and system chrome are copyrighted and are not used. Icons are original SVGs. Wallpapers are original gradients. Lumen 69 adds a boot-loaded local phrase helper, dock magnification, and extra mock apps (News, Markets, Books, Podcasts, Chess, Screen, Canvas).

Ask is a voice and text helper. Boot loads `data/mind69.json`. Longer answers can use a public text demo in the browser. Speech uses the browser mic and voice when you allow them.

Live: https://carterobviously-creator.github.io/grok-macos/
