# Lumen Desktop

A **browser mock** of a modern glass-style desktop OS inspired by recent macOS Liquid Glass design (macOS 27 Golden Gate refinements).

**Entertainment only.**

**Not macOS. Not Apple. Not the real Siri. Not Apple Intelligence. Not the App Store.**

Official Apple icons, wallpapers, Liquid Glass trademarks, and system chrome are copyrighted. This project uses original SVG icons (squircles with layered glass highlights), original CSS glass surfaces with specular and blur, and original wallpaper scenes. No official Apple assets are used.

The assistant (Aura / mock Siri) is a local helper with a tiny LLM phrase model loaded at boot, plus optional third-party AI text endpoint (pollinations) for longer conversational answers. It can open mock apps, save notes, add reminders, do simple math, and speak (optional).

## Recent refinements (Lumen 79)
- Richer original SVG icons with enhanced gradients, larger canvases, and layered glass highlights
- Improved Aura AI prompt for more natural, concise, slightly witty mock assistant replies
- Better speech synthesis rate and pitch
- Continued Liquid Glass polish on specular, blur, and dock effects
- Full working mock apps and boot-time tiny local LLM phrase model

## Features
- Boot screen with tiny local LLM load
- Lock screen, desktop with widgets, dock magnification, Launchpad, Mission Control, Spotlight-style search
- Control Center with Liquid Glass intensity slider
- Full working mock apps: Files, Notes, Calculator, Web, Gallery (app store mock), Settings, Calendar, Music, Photos, Terminal, Mail, Maps, Stickies, Weather, Clock, Writer, Reminders, and more
- Siri-style AI assistant (local + optional cloud) with speech input/output
- Original high-detail icons and glass effects
