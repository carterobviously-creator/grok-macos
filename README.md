# Lumen Desktop

A **browser mock** of a glass-style desktop.
Entertainment only.

**Not macOS.
Not Apple.
Not Siri.
Not Apple Intelligence.
Not the App Store.
**

Official Apple icons, wallpapers, Liquid Glass trademarks, and system chrome are copyrighted.
This project uses original SVG icons, original CSS glass surfaces, and original wallpaper scenes.

It can open mock apps, save notes, add reminders, do simple math, speak, and optionally use a public text demo for longer answers.
It is not a product AI and not an Apple assistant.

## Lumen 73 refinements
- Smoother dock magnification with better falloff and lift
- Liquid Glass specular highlight via CSS ::before and dynamic --specular variable
- Enhanced Aura local replies + prefer cloud for open-ended questions
- Better window drag feel
- Boot screen mentions tiny local LLM phrase model
