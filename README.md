# Lumen Desktop

A **high-fidelity browser mock** of a modern glass-style desktop OS inspired by recent macOS Liquid Glass / Golden Gate 27 design language (refined for Lumen 92).

**Entertainment only.**

**Not macOS. Not Apple. Not the real Siri. Not Apple Intelligence.**

No official Apple assets are used. Icons are original SVGs with layered glass highlights and specular depth. Surfaces are original glass-style CSS with enhanced refraction, blur, and dynamic highlights. Changed enough from any real OS to be a distinct entertainment mock.

The assistant (**Aura**) loads a tiny local LLM phrase model at boot, plus a free third-party AI text endpoint (pollinations.ai) for longer conversational answers by default. It can open mock apps, save notes, add reminders, do math, rewrite, summarize, generate ideas, control the desktop, and speak (optional). Voice input supported where the browser allows.

## Features
- Boot screen with tiny local model load + AI readiness
- Lock screen, desktop with widgets, dock magnification (improved hover physics), Launchpad, Mission Control, Spotlight-style search
- Control Center with Liquid Glass intensity slider & brightness
- Full working mock apps: Files, Notes, Calculator, Web, Gallery (app store mock), Settings, Calendar, Music, Photos, Terminal, Mail, Maps, Stickies, Weather, Clock, Writer, Reminders, Messages, Contacts, Sketch, Board, and more
- Aura AI assistant with local + cloud replies (enhanced prompt for natural conversation)
